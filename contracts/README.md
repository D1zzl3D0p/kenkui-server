# Contract authority

Public v1 resource types originate in the selected reviewed OpenAPI artifact. Studio's
`contracts/local-api/source.json` records its exact schema provenance; regenerate
client types only for reviewed schema changes. `neon/baseline.json` and route-matrix.md
are frozen migration evidence, not fixtures to regenerate until a port passes.

Python Kenkui owns document parsing, normalized speech counts, planning and audio
semantics. Public API validation is characterized against Python Pydantic during
the migration. TypeScript pricing/canonical serialization and credit transitions
must match shared synthetic vectors and PostgreSQL invariants; neither cached
balances nor client character counts authorize admission. PostgreSQL migrations
and guarded transactional operations own durable state, identity and ledger history.

Environment capabilities describe supported local/hosted behavior. Core main's PDF
and newer chapter-title behavior is not automatically part of the frozen EPUB-only
hosted release. Keep that feature reconciliation explicit before selecting a new
runtime core. Pydantic error wording/coercion simplification is deferred until live
acceptance and a documented client-compatibility decision; this cleanup preserves v1.
